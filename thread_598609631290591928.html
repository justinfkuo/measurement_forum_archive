Admin #2 • 7/31/19 @ 12:42 PM

I believe the answer is to just type in the calibration course # in the text box labeled "Calibration Course Certification Code" and then put its length in the text box above that.

The text box labeled "Calibration Course Used" is for selecting a course you have previously entered using this new system. If you select one of those from the drop down list (you probably don't have one of those yet) I believe it will fill in the 2 text boxes below that for you.
