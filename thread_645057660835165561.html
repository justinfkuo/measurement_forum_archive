A friend is measuring a point to point half marathon here in CT that starts and finishes in different towns. Which point should be used when listing the course for certification?

The Start. 

jimgerweck #3 • 9/24/20 @ 5:53 PM

I would tend to agree, although I'm sure an argument could be made the other way, too. I was just wondering if there is an official rule about it.

Race Resources LLC #4 • 9/26/20 @ 1:25 PM

The RRTC Map Requirements of September 2014 as published on USATF.org references only the Finish. The new map requirements as revised as of January 16, 2020 and emailed to measurers by Justin Kuo on January 20th states "The course city and state for the start and finish must appear on the primary map page. The course start city and state is required if different from the finish."

I find this wording confusing. This should be revised for clarity, IMO. It should be posted on USATF.org in place of the outdated version still there.

It seems to me that both towns should be listed on the map.

Admin #5 • 9/26/20 @ 1:45 PM

To see the latest info about rule changes, guidelines, etc., go to the rrtc.net website. We do not have direct control of the course measuring/certification section of the usatf.org website, so updates there happen much more slowly.
