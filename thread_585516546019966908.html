Course Map Labeling

jimgilmer #1 • 8/5/07 @ 6:43 PM
What is the correct interpretation of the following directive in the procedures manual?
"Clearly label all streets and roads used for the course." Course Measurement and Certification Procedures

Does this incluce all streets/roads intersecting a course? Or does it only apply to those streets/roads on which the course is actually run?
genenewman #2 • 8/6/07 @ 4:28 AM
I would first label the streets on which the course is actually run. However, if the map is not too busy then I would include some other streets.

Gene Newman

peteriegel #5 • 8/6/07 @ 7:02 AM
A course map should have the name of the race and the town where it is located. Some don't. I try to fix this when I do my certifier work.
jimgerweck #6 • 8/6/07 @ 12:00 PM
I generally try to include cross streets at major intersections, or turns where it might be confusing. But labeling every cross street, especially for a longer course through an urban area (e.g. Chicago or NYC Marathons) might make the map too busy, and actually less clear.
jaywight #7 • 8/6/07 @ 1:57 PM
Label the intersecting streets where it would help the user interpret the map. Otherwise don't bother; excessive superfluous detail just makes the map harder to read.

One thing i always try to do is depict the configurations of intersections accurately. If the intersection is a "T", I draw it as a "T", so the user of the map is looking for a "T" intersection.
